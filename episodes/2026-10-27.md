# PHP2Shell enters KEV; Brotli rebuilds widen the patch queue

*Confirmed PHP2Shell exploitation brings a federal patch deadline and industrial-product advisories. Brotli fixes reach .NET and Windows PHP, while active campaigns target online shops, Dahua cameras and developer repositories. Older iPhones also get an already-exploited flaw fixed.*

Good morning, it's 5:22 AM. Tuesday, the twenty-seventh of October, twenty twenty-six.

There's now solid exploitation evidence for PHP2Shell, separate from the government-agency attribution withdrawn yesterday. Perplexity's honeypots caught thirty-five working shells from two addresses on Saturday. CISA has added CVE-2026-109618 and CVE-2026-109619 to KEV, with Thursday, the twenty-ninth, as the fix deadline for US agencies. I'd treat that as a ceiling, not a booking slot.

The captured chain used four stages against PHP 8 point 4 point 26 under Apache mod_php: exhaust memory, then leak it, before executing a shell command. That traffic matches the public proof of concept for the first flaw; no second-stage download was observed. The application framework doesn't protect you from a bug underneath it. Patch to 8 point 5 point 12 or 8 point 4 point 27; on older branches, 8 point 3 point 36 or 8 point 2 point 35.

And check the PHP inside appliances. Industrial vendors now have product advisories: Schneider's Security Expert fix is 1 point 48 point 4 point 0; Belden's NetModule NRSW has no patch, so disable its web interface. Infrawatch counts about nineteen per cent patched globally, with the UK at a quarter. A pentester also bypassed ASLR on a live target for a two-thousand-dollar Bitcoin prize. Weaponisation demonstrated, not automation at scale. Hunt for unexplained worker crashes alongside unusual multipart requests.

That PHP patch queue now has a Windows wrinkle: the Brotli follow-up. The rebuilt packages need the dash-one suffix, carrying Brotli 1 point 2 point 1. Same PHP versions, but php dash v won't distinguish them; check the filename and SHA-256. That's an irritatingly easy way to declare victory one rebuild early. cURL automatic decompression reaches the flaw, and Guzzle enables it by default.

Microsoft's emergency fixes are .NET 8 point 0 point 33 and 9 point 0 point 22, or 10 point 0 point 14 and .NET 11 Release Candidate 3. Exposure requires opting into Brotli processing, including HTTP decompression. Restart applications after updating; self-contained builds and container images need rebuilding. Visual Studio and PowerShell have updates too. There's still no reported malicious exploitation.

For PAN-OS, the exposed dataplane needs both Brotli inspection and TLS decryption enabled; 10 point 2 and 11 point 1 aren't affected, nor is Panorama. Hotfixes are scheduled from today through Friday. Until yours lands, run set system setting brotli-encoding disable. One hotfix generally covers PHP and Brotli, but 11 point 2 point 10 dash h sixteen covers only PHP; h seventeen covers both. And the reach keeps widening: JFrog demonstrated an FFmpeg path through libjxl using a JPEG XL image, while Apache Arrow faces denial of service. Fortinet's still investigating FortiOS. With this much emergency noise, the actual enabled feature matters more than another nickname.

Away from patch availability and into active intrusions, Sansec counts nine hundred and fifty-three infected shops, mostly Magento, whose cms_block loader screens out scanners and serves code to real shoppers; the final payload hasn't been captured. Audit cms_block and cms_page alongside administrator accounts: a fully patched store was reached through a rogue admin, so patch status isn't clearance.

That persistence problem extends to cameras: CERT-UA warns of compromised Dahua devices with unauthorised accounts, so disable Easy4IP cloud access where unnecessary and update firmware. Hunt.io says rogue accounts and recovery codes can survive password changes and most factory resets, though it hasn't linked these cases to its earlier campaign.

And for developers, JFrog says the testmetest npm worm armed forty-two GitHub repositories, hiding roughly thirteen-megabyte payloads that code search won't return. Check repository files and execution hooks directly, and isolate affected machines before rotating credentials from a clean device: revoking the stolen GitHub token can trigger a home-directory wiper.

For a more straightforward patch job, Apple's three hundred and four fixes include the already-exploited CoreGraphics flaw, CVE-2026-86950, now fixed on the older line in iOS and iPadOS 18 point 7 point 11. Prioritise those devices; none of the newly disclosed flaws is marked exploited.

But a convincing support chat needs no software flaw: Arctic Wolf describes hundreds of cases where an inbox flood precedes fake IT support on Teams, persuading victims to grant remote access, with related activity ending in Chaos ransomware. Restrict external chats to approved partner domains and investigate that pairing even without suspicious URLs; meanwhile, Mozilla's archive replay has merely reached MFSA 2013-76 and 2013-93.

I'd give the appliance patch queue an owner before the morning handover. For Windows PHP, ask for the package filename as evidence of completion, rather than another reassuring version screenshot. Hope your Tuesday starts quietly.
