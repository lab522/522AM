# Outlook hash theft leads another thousand-fix Patch Tuesday

2026-11-11 · [listen](https://raw.githubusercontent.com/lab522/522AM/main/episodes/2026-11-11.mp3)

Brought to you by [Lab522](https://www.lab522.co.uk)

*Microsoft's November patches include an exploited Outlook flaw that exposes NTLMv2 hashes, while Xen Orchestra attackers can reach root on managed hosts. There's also confirmed Barracuda exploitation, new N-central scanning and a busy patch queue across browsers and enterprise software.*

Good morning, it's 5:22 AM. Wednesday, the eleventh of November, twenty twenty-six.

Microsoft has passed a thousand fixes for the second month running, but the one attackers are already using scores just six point five. I'd put that ahead of the impressive-looking criticals. It's CVE-2026-124194 in Outlook: opening a specially crafted message file makes the client connect to an attacker's network location without the usual external-content warning, handing over your NTLMv2 hash. That can be relayed live to impersonate you, or cracked offline. The Preview Pane doesn't trigger it.

Patch supported classic Outlook installations first, including Microsoft 365 Apps and Office LTSC 2021 and 2024. CISA's deadline for US agencies is the twenty-fourth of November. Then prioritise Exchange and domain controllers: Windows Search has a nine point eight code-execution flaw reachable through an attachment Exchange indexes automatically; Windows LDAP has another nine point eight reachable through crafted calls. Neither needs user interaction. ZDI counts thirty wormable flaws this month and flags Schannel's pre-authentication code execution as more likely to be exploited. And there's a support-clock problem underneath the patch queue: November is the last monthly update for Windows 11 23H2 Enterprise and Education. .NET 8 LTS and PowerShell 7 point 4 LTS reach their end dates today.

But the management-console emergency is rather smaller than a thousand bugs. An empty JSON object is enough. Vates says attackers are exploiting Xen Orchestra, the console controlling XCP-ng hosts and virtual machines: a crafted authentication cookie becomes an empty object, which the token store treats as an unfiltered lookup. It returns the first token; if that's unexpired, the attacker becomes its owner. Admin access can lead to root across managed hosts. That's an astonishingly short journey.

Install Xen Orchestra 6 point 9 point 1 stable or 6 point 10 point 0 latest, with xo-server 5 point 211 point 2 or 5 point 213 point 1 respectively. Otherwise isolate the console on a dedicated management network. Hunt through HTTP monitoring, not just application logs, for the crafted cookie; a VM named pivot2 is another indicator. If you find evidence, rotate all passwords and secrets.

Back in the scheduled patch queue, SAP has four maximum-severity fixes: update the kernel and Web Dispatchers together, and check the Gateway proxy access controls. On release 7 point 93, patch level 419 is still vulnerable; use the updated 401 Stack Kernel or 420 onwards, with 402 also fixed once released. And Chrome's eighth exploited zero-day this year is an XML use-after-free: open About Google Chrome and relaunch into 157 point 0 point 8103 point 50 or later. Android users need the Google Play update too; US agencies have until the twenty-fourth.

Apple has now joined the patch list for the exploited Brotli flaw we covered earlier, alongside new iMessage fixes stopping outsiders joining group chats or new members reading earlier messages. Install the platform updates; iOS and iPadOS 27 point 2 point 1 cover those issues, but the 18 point 7 point 12 and watchOS 26 point 6 point 1 notes don't list them. Adobe's November batch is much bigger than October's, at roughly a hundred and ten fixes: prioritise Connect and Experience Manager, with six Connect flaws scoring ten. Adobe reports no attacks, so the creative tools can take the normal workstation cycle.

For Ivanti, match installed versions against the five advisories covering User Workspace Manager and Sentry, plus Endpoint Manager Mobile, Cloud Services Application and Endpoint Manager; there's no evidence of exploitation. Ivanti expects more disclosures as it expands LLM-assisted security work. And FortiAuthenticator has a hard-coded password allowing unauthenticated access in certain circumstances: upgrade the 8 point 0 branch to 8 point 0 point 4, or 6 point 6 to 6 point 6 point 11. No known exploitation, but no workaround either.

The next deadlines do come with exploitation evidence: CISA has added Cisco BroadWorks' XML external-entity flaw and Openwave Webtop Media Transcoder to KEV, both due by the twenty-fourth for US agencies. BroadWorks needs the applicable 2026 point 07 or RI point 2026 point 07 release; Openwave needs 1 point 1 point 22 point 0.

For exposed appliances, Friday comes sooner: Barracuda now confirms attackers are chaining the Email Security Gateway flaws we mentioned last week to get root, with a thirteenth-of-November federal deadline. Restrict the admin interface to trusted internal networks and verify the automatic patch actually landed; otherwise apply the relevant product hotfix manually and investigate possible compromise. Meanwhile, N-able now reports scanning associated with Able2Shell, though it still reports no successful customer exploitation. Yesterday's midday Eastern hotfix target has passed without a remediation build in the latest guidance here; what bugs me is that N-able also didn't answer whether it can check its server logs for exploitation.

Away from patching, ESET attributes the Cereal espionage toolset to Turla: compromised government Exchange servers in Kazakhstan and Romania became their own command-and-control infrastructure, with Romanian collection targeting NATO and EU correspondence. This is a hunt, not a patch: use ESET's indicators and inspect EdgeTransport.exe injection or hijacked existing transport-agent handlers, because Cereal adds no new agent.

And away from real incidents, Mozilla's archive replay has widened to more than eighty entries, reaching back to MFSA 2009-12 through 2010-27. Extend yesterday's suppression into two thousand and nine and check for automatically opened tickets; those aren't fresh emergencies.

I'd get a named owner on the exposed Xen Orchestra consoles before the wider patch rollout starts. For N-central, a promised time isn't confirmation that recovery is safe. Hope your Wednesday gives you a clear run at it.
