*Another exploited NetScaler zero-day means another emergency update, while Atlassian patches unauthenticated file access across eight self-hosted products. Plus exploited management tools, Denmark's population-register breach, and the FBI's explanation for its PeopleSoft compromise.*

Good morning, it's 5:22 AM. Tuesday, the sixth of October, twenty twenty-six, covering the seven days since the last episode.

[short pause] A freshly patched NetScaler isn't necessarily a safely patched NetScaler. Citrix has fixed its third publicly exploited zero-day in two weeks, after administrators saw updated appliances rebooting on Friday. One specially crafted request can knock the appliance offline. Keep sending it, and the authentication gateway stays unavailable — along with access to whatever sits behind it.

CVE-2026-88779 is a memory-buffer flaw in customer-managed NetScaler ADC and Gateway, Citrix's load-balancing and remote-access appliances. It needs a SAML service-provider or identity-provider configuration. Citrix-managed cloud services and Adaptive Authentication aren't affected. This is separate from the earlier flaws; watchTowr suspects attackers used crashes to accelerate exploitation of another bug, but that's a suspicion, not an established technical link.

I'd reopen the change ticket, however recently you closed it. Upgrade the ordinary branches to 14 point 1 build 73 point 41 or 13 point 1 build 64 point 28; the FIPS and NDcPP builds need 14 point 1 build 73 point 41 FIPS or 13 point 1 build 37 point 282, as applicable. If you can't yet, deploy Citrix's Global Deny List signatures and run its compromise-checking script. CISA's federal deadline is tomorrow, October seventh.

And while that gateway controls entry, the next flaw doesn't need a login at all. Atlassian's nine point three path traversal lets attackers read known files in the web application's root directory across eight self-hosted Data Center products. That means Bitbucket and Confluence, both Jira editions, Bamboo and Crowd, plus Crucible and Fisheye. The attacker needs the exact filename and path; they can't browse the directory. Sensitive files in that folder are the catch.

For CVE-2026-21589, move to Atlassian's fixed long-term-support release or later. Crucible and Fisheye need 4 point 9 point 15; check the product-specific bulletin for the others, and beware conflicting Crowd and Bamboo version fields. Cloud customers need no action. If patching must wait, take the instance offline or apply Atlassian's temporary blocking rules, then hunt access logs after URL-decoding request lines up to twice. Self-hosted exploitation hasn't been confirmed. What bugs me is that Atlassian can't tell you whether your instance was touched, and its blocking rules aren't a substitute for patching.

Back at the edge, FortiMail's exploited path traversal lets unauthenticated HTTP requests write arbitrary files underneath the mail gateway; CISA's October fourth deadline has already passed. Install the fixed release for your branch, and if its web interface was internet-facing, hunt unexpected files before rotating appliance credentials and stored secrets. That same management exposure matters for Cisco Catalyst SD-WAN Manager: an exploited hex-encoding bypass hands an unauthenticated requester admin API access to the controller for the whole fabric. Its federal deadline was October third; use Cisco's branch-specific fixed build, check the advisory especially carefully for 26 point 2, and restrict management access while upgrading.

There's movement on the AI-found bugs, too: a second Mythos-linked flaw now has exploitation attempts, this time session forgery in Rejetto HTTP File Server, with probing first detected on October first. Patch to 3 point 2 point 1 or later, preferably 3 point 3 point 4; the activity observed so far is reconnaissance, not confirmed victim compromise. From servers to people specifically targeted, Apple says a malicious-file code-execution flaw may have been used in an extremely sophisticated attack. Deploy iOS and iPadOS 26 point 7 point 1, macOS Sequoia 15 point 8 point 1 or Tahoe 26 point 7 point 1; the federal deadline passed on October second.

But a working login can be just as damaging: attackers abused a Danish company's lawful population-register access to steal identity details, including CPR numbers, for roughly eight point eight million people. That access is now terminated; I'd check supplier lookup rights and alert on unusual lookup volume, because a legitimate account plainly isn't a limit on how much it can take. And sessions are the route into Zammad, the helpdesk platform, where two exploited flaws take attackers from session hijacking to code execution as its service user, then locally to root. Move beyond 6 point 5 point 4 and 7 point 1 point 3 using the vendor's current release, and investigate compromise rather than treating the update as a clean bill of health.

That distinction between a planned fix and an installed one has caught up with the FBI: it now blames a missed PeopleSoft patch and has removed an Accenture contractor, while Mandiant assesses the route as URL encoding past a WAF rule on PSEMHUB — so verify deployment and hunt those requests. Separately, alleged ShinyHunters leader Rey has reportedly been detained in Jordan and is cooperating; the FBI confirms multiple arrests, while the group has resurfaced on Telegram after its leak site was taken down.

And attackers don't always need an exploit: SANS found a fake invoice PDF using an OpenAction URI to fetch a script, show a decoy and install an Action1 remote-management agent. Hunt the A1Agent service where Action1 isn't authorised; its connection to the vendor's own cloud isn't reassurance. Finally, don't mistake Mozilla's resurfaced emergency advisory for a fresh attack: those two exploited Firefox bugs were fixed in March twenty twenty-two. No new action for current browsers, but an inventory hit older than those fixes is a pinned machine worth investigating.

I'd give the person handling emergency changes room to verify deployment, not just approve it. And I'd keep a close eye on gateway availability while that work lands. Hope Tuesday gives you a quieter afternoon.
