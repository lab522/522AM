*An image-decoder flaw helped researchers reach OpenAI's internal code, despite an upstream fix already existing. Public Linux root exploits add urgency to kernel updates, alongside WordPress patches and fresh details on Gyazo's breach. Microsoft's cloud fixes are done, but a Windows update still needs installing.*

[cheerful] Good morning, it's 5:22 AM. Saturday, the nineteenth of September, twenty twenty-six.

[serious] A security fix that never gets labelled a security fix can sit upstream while everyone downstream stays vulnerable. That's the uncomfortable bit of HEIF Heist: Hacktron researchers used Claude to turn a libheif memory bug into access to OpenAI's internal monorepo in under seventy-two hours. They entered through its Discourse community forum on July twenty-fifth, using a corrupted image. Discourse's normal image checker couldn't handle HEIF in that setup, so it handed the upload to ImageMagick, which passed it to libheif. [curious] The fallback was the door. A heap buffer overflow in the decoder let them hijack the server; a separate OpenAI sign-in flaw gave forum tokens excessive permissions, opening employee ChatGPT and Codex accounts. They proved access with an internal pull request.

[serious] The library bug had already been fixed upstream, but without a security designation or CVE, it missed the usual patch cycle. What bugs me is that a clean vulnerability dashboard wouldn't have told you to move. Claude Opus 4 point 8 couldn't make the exploit work; Opus 5 did. [calm] OpenAI fixed its side in about fourteen hours. For Discourse, apply its fix and follow the advisory's rebuild guidance, including image-processing sandboxing. Elsewhere, take the latest upstream libheif patches wherever you decode uploaded images, and trace those fallback paths. Review what your forum's single sign-on tokens actually permit. The researchers warn the same primitives reach other major services; that's not evidence they've been attacked.

[short pause] [serious] And once somebody has a foothold, four newly public Linux kernel exploits offer a route to root. Asim Manizada held publication while distributions shipped fixes; there's no reported real-world exploitation of these four. They're networking memory-safety bugs: DirtyAH6 and TUNderflow mishandle bounds or sizes, while PPPoEject uses a stale pointer and DiagSpill wraps an endpoint counter. [confident] I'd prioritise shared build machines. Check your distribution's advisory confirms all four fixes, rather than guessing from its kernel number. Disabling unprivileged user namespaces blocks the ordinary-user route to the first three, but not DiagSpill, which only needs the S-C-T-P module. Disable unused affected networking modules if patching has to wait. Separately, CISA has added actively exploited kernel flaws CVE-2025-39682 and CVE-2025-39964 to its catalogue. CVE-2026-53266 joins them, with all three due for US agency remediation by Monday, September twenty-first.

[calm] Back at the upload-facing end, WordPress's Click2Shell lets a crafted link opened by a logged-in administrator force a theme installation from the official directory, with a further chain to code execution. Install 7 point 1 point 1 or your branch's matching security update. [serious] And installation is also worth watching on Windows: Huntress saw Settra ransomware deploy MeshAgent for persistence, with a vulnerable driver added in September to attack security tools. Hunt unauthorised MeshAgent installs and execution from C colon backslash Perflogs; the crew also deliberately dismantles recovery, so backups need to survive outside the encrypted host.

[long pause] [serious] The consequences go beyond files: foreign actors manipulated drinking-water control equipment at two small Colorado utilities in late August, each serving fewer than two hundred people. If you support a small utility, check who can reach its controls from outside. And yesterday's Gyazo breach has moved on: the service is now offline preventively, with access to affected files temporarily disabled, and it says the flaw was fixed on September twelfth. Newly disclosed exposure includes login session identifiers and Google single sign-on email addresses; image metadata also contained location data and recognised text, so check those Google sign-in sessions.

[calm] There's a happier distinction between a service being unavailable and a service being patched: Microsoft has fixed eighteen Azure and A-I product flaws server-side, including a ten point zero privilege-escalation flaw in Azure A-I Foundry, with nothing for customers to install. Windows 11 version 26H1 does need the separate out-of-band update, K-B five one two nine one nine four, build 28000 point 2956. [curious] And a useful refinement to yesterday's QUERY discussion: nginx proxies it but doesn't cache it, while its limit-except pattern silently rejects it. Apache needs configuration changes to recognise the method and handle cross-origin requests; dot NET 10 supports it out of the box.

[confident] I'd give image-processing owners the upstream patch check, not just a scanner ticket. For kernel changes, make sure the fixed kernel is actually running before calling the maintenance window done.
