# Plex2Shell turns media servers into somebody else's proxy

*Plex attacks began a day after exploit code appeared, while a poisoned Rank Math PRO update leaves backdoors that survive patching. There's also a workaround for Exchange disruption, fresh evidence from appliance compromises, and urgent action for UpdraftCentral users.*

Good morning, it's 5:22 AM. Tuesday, the twentieth of October, twenty twenty-six.

A day. That's all it took for working Plex2Shell exploit code to become attacks against internet-facing Plex Media Servers. The code appeared on the sixteenth; a researcher's honeypot caught infections on the seventeenth. Those NAS boxes streaming films are now being recruited to mine cryptocurrency and proxy somebody else's traffic.

The chain joins four bugs. An unauthenticated request reaches internal functions and obtains the owner's admin token; another request fetches an attacker-hosted Linux payload. The final flaw writes it into the Codecs directory and executes it with the Plex service's privileges. No stolen password needed. The honeypot caught an XMRig process called mylovelyminer, alongside a backdoor and reverse proxy called myawesomeproxy. Charming names. Rather less charming tenants.

If you run Plex Media Server older than 1 point 43 point 3 point 10861, update now, then hunt for those names. Internet-exposed servers on the default Plex port are being scanned and infected. I'd take an exposed box offline while checking it: installing the fix doesn't evict malware already there. And the proxy bothers me more than the miner. It's your residential connection carrying someone else's traffic.

But trusting the update itself is the problem with Rank Math PRO, the paid WordPress SEO plugin. Copies of 3 point 0 point 123 downloaded or delivered as updates between twenty-oh-two UTC on the fifteenth and seven twelve UTC on the sixteenth contained malware. The free WordPress.org plugin isn't affected. The version number alone won't tell you whether a copy was poisoned.

Activate a tainted copy and a visitor can trigger recreation of its hidden backdoor, even after an update. Deactivation isn't enough either. I'd restore the site and database from before that window, scan, then rotate every credential the web server could reach before installing clean version 3 point 0 point 124. Without a clean backup, follow Rank Math's full removal procedure; this isn't just deleting a plugin folder. Rank Math still hasn't said how its distribution system was breached.

And sometimes a legitimate update breaks the service instead. Microsoft's October Windows Server updates can disrupt Exchange on Server 2019 and later, leaving OWA sign-ins failing or mail stuck in the Outbox. A new Endpoint Mapper limit allows five hundred and twelve simultaneous Endpoint Lookup calls; busy Exchange servers can exhaust it.

There's a registry workaround while Microsoft develops a fix: under HKEY LOCAL MACHINE, SOFTWARE, Microsoft, Rpc, set the DWORD EpmapSavedContextCap to sixty-five thousand five hundred and thirty-six, then reboot. Monitor afterwards, particularly for MapiExceptionMdbOffline and application Event one thousand and six. Crucially, don't uninstall the October Exchange security updates: they're not the cause. A targeted workaround beats pulling the wrong patches.

Back to trusted software carrying dangerous authority: ConnectWise's investigation began on the fifteenth, correcting yesterday's timeline, and we now know one tenant's MS Teams application made itself Global Administrator and created secrets on other applications. Keep connections disabled pending restoration instructions and audit those secondary credentials; ConnectWise has revoked affected certificates across all users, but lacks visibility into partner environments and has no restoration date. With Siemens, by contrast, no update channel was breached: Romulus ClickFix attacks paired genuine Software Center with malicious DLLs that version 3 point 5 point 8 point 7 loaded without validating. Confirm it's launched and updated to 4 point 0 point 9 point 8.

That move from an initial foothold to something more powerful also turns up in Unit 42's PAN-OS follow-up: attackers pivot from GlobalProtect into vCenter, disable execInstalledOnly on ESXi and dump credentials from a domain controller's virtual disk. Apply the advisory fixes or workarounds, then hunt beyond the gateway using the new GlobalProtect indicators. And Rapid7's NetScaler investigation now shows a second flaw crashing the appliance so its crash handler executes retained attacker text as root after reboot. Hunt for /nsconfig/.slap and check the HA peer too; implants were synchronised across it, with configuration and key material staged for theft.

The investigation window has widened for BeyondTrust Remote Support as well: Rapid7 dates both known compromises to the twenty-ninth of August. CISA now requires forensic triage; look back that far for BARECLAW or the unauthorised /uidchanarge route in the appliance's HAProxy configuration.

There is better news on available fixes: F5 now has out-of-band NGINX builds where several products previously had none, so check the advisory for your product and install its update. Eptura Archibus, the facilities-management platform, also has fixes for Rapid7's newly discovered flaws; ask Eptura which release contains them and keep its web front end off the public internet meanwhile.

Updates need scrutiny as well as speed, though: Wiz points to the separate axios and keyv compromises spreading malicious packages before vulnerability databases catch up. Check build histories and stop automatically taking the newest foundational dependencies; a clean vulnerability scan isn't proof of clean code. On WordPress, Wordfence says stolen UpdraftCentral connection keys are actively installing malicious plugins following the TeamUpdraft website breach. Disconnect sites from UpdraftCentral and revoke and regenerate those keys; audit installed plugins and treat unexpected additions as compromise.

And the uncomfortable backdrop: Moody's puts the median patching time for known exploited flaws at eighty-seven days. Pull an aged list of open exploited vulnerabilities so the oldest exposures aren't quietly disappearing beneath newer tickets.

I'd give exposed Plex servers immediate attention, while treating a tainted Rank Math installation as recovery work rather than an update job. For Exchange, check the symptoms before changing the registry. Have a good Tuesday.
