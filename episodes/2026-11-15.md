# Old agent traces opened Cursor’s marketplace to attackers

*Cursor explains how stolen credentials led to the malicious Claude Code extension, with customer data taken along the way. A disrupted North Korean campaign used familiar faces to sell fake meeting fixes. Plus two WordPress flaws needing workarounds, and what officials know about the FAA ground stop.*

Good morning, it's 5:22 AM. Sunday, the fifteenth of November, twenty twenty-six.

We’ve finally got the missing link in that malicious Claude Code extension story from October: how the attacker got into Cursor’s marketplace. Cursor, the AI code editor, says it began with an access key stolen from its inference provider, Fireworks AI. That opened a read-only bucket of old coding-agent traces, mostly from twenty twenty-five, from users without Privacy Mode enabled. Some contained unredacted API credentials. Those unlocked further systems, including a credential that let the attacker publish directly to the marketplace cache. Read-only storage, very much not read-only consequences.

The theft went beyond the extension. Archived non-production source repositories and support emails were taken; so were usage metrics and credentials customers had shared with support. Cursor says fewer than zero point zero five per cent of users had traces exposed, and fewer than zero point zero one per cent had API credentials compromised. Privacy Mode code and prompts weren’t affected, nor were production infrastructure or official releases. Anthropic’s legitimate extension and Open VSX weren’t compromised either. Cursor has revoked the Fireworks key and moved inference elsewhere; it’s also rebuilt the marketplace and redeployed production infrastructure. If you installed the affected extension on the twenty-ninth of October, follow Cursor’s remediation guidance and hunt for the attacker’s SSH key and persistence. I’d also rotate credentials shared with support or potentially captured in agent traces: removing the extension doesn’t deal with those. Wiz puts this in its “Black October” wave; at Railway, stolen customer authentication secrets led to roughly seven hundred and forty thousand dollars in fraudulent AI charges.

And another route into developers’ machines began with something rather more convincing than an unexpected download: a video call with someone they knew. US authorities have seized cloud infrastructure behind FaceStealer, a North Korean campaign that stole more than four hundred million dollars in cryptocurrency over eighteen months. Arctic Wolf links it to BlueNoroff and counted six hundred and seventy-seven targets across fifty-eight countries.

Hijacked accounts sent meeting invitations. Attackers then played secretly recorded footage of familiar people, claimed a technical fault, and offered a fake fix that installed malware stealing crypto data and meeting credentials. Authorities found more than nine hundred webcam recordings. That’s the bit I’d challenge in any awareness exercise: recognising the face isn’t verification. Targets included crypto executives and open-source developers; the FBI confirmed approaches to npm and Rust crate maintainers. Verify unexpected invitations independently, then join through the official app using an invite code. Keep the camera off unless needed, and don’t run a meeting’s suggested repair script or installer.

From a fix you shouldn’t run to a plugin you should stop running: WordPress’s Cloud Storage Manager for Fluent Forms through 1 point 2 point 0 lets unauthenticated attackers write outside its downloads directory, with PHP execution possible if the file lands somewhere web-accessible. CVE-2026-120522 scores nine point eight; there’s no fixed version listed, so deactivate it pending a patched release. Not every disruption has an attacker behind it, though: Friday’s FAA nationwide ground stop lasted more than four hours, with Cirium counting over eight thousand two hundred flights cancelled that evening and at least three thousand more on Saturday. US officials found no evidence of hacking; the transport secretary blamed a routine equipment upgrade, but the FAA’s root-cause analysis remains open and the FBI is reportedly examining a software update. Back on WordPress, AutomatorWP Pro’s webhook addon through 1 point 4 point 4 can let an unauthenticated caller reset even an administrator’s password, but only with a particular automation: Receive Webhook feeding Update-User, a blank User ID, and Password mapped to the webhook password tag.

For CVE-2026-126173, also nine point eight, there’s no fixed version listed: disable that automation or the addon, then review administrator accounts.

I’d put those exposed WordPress paths ahead of waiting for a release announcement. For Cursor users, check whether the response covered stolen credentials as well as the developer machine. Hope you get a quiet Sunday.
