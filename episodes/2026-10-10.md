# Ahsay backup servers breached, NetScaler needs another patch

*Attackers are chaining unpatched AhsayCBS flaws to take over backup servers, while NetScaler needs another upgrade for SAML deployments. Fake GitHub security workflows are stealing CI secrets, and exploitation attempts have now reached SonicWall's newly patched SMA1000 flaw.*

Good morning, it's 5:22 AM. Saturday, the tenth of October, twenty twenty-six.

Your backup console is the way in this morning. Attackers are chaining two unpatched flaws in AhsayCBS, the central backup management platform used by service providers, to get remote code execution without logging in. Huntress saw attacks begin on Wednesday and counted at least five organisations hit. The nasty detail: the vulnerability records say version 10 point 3 point 4 fixes it. Huntress tested that latest release and found it vulnerable too. There's no patch.

A random token passes the Replication Receiver API's authentication check; command injection then lets the attacker configure a malicious receiver and plant a JSP webshell in the application's served directory, running as System. That's control of the backup host, not merely stolen compute. XMRig arrives disguised as edge dot exe, with persistence through a service called MicrosoftEdgeUpdateSvc. A PowerShell script stops mining when Task Manager opens. Very considerate of it.

I'd restrict the management web interface before doing anything else: trusted IP addresses only, or a VPN. Don't let that claimed fixed version close the ticket. Huntress has indicators and four Sigma rules; check the served application directory for webshells, and investigate that Edge-named service. One intrusion also brought the vulnerable WinRing0x64 driver into TEMP for kernel-level access. If compromise is confirmed, restore the whole host from a known-safe backup: removing the miner doesn't account for other backdoors.

At least the next edge appliance has a fix, though NetScaler administrators could reasonably ask for a weekend off. Since Tuesday's coverage, a fourth critical flaw has landed: CVE-2026-107406, a nine point five memory overflow giving remote code execution or a crash in SAML deployments. Citrix says it knows of no unmitigated exploits. That's different from the earlier scramble, but appliances patched to the fourth of October level still need upgrading.

Check whether customer-managed ADC or Gateway acts as a SAML identity provider or service provider; some recent builds are affected only in the identity-provider role. The fixed releases are 14 point 1 dash 73 point 46 and 13 point 1 dash 64 point 29. For 14 point 1 FIPS, it's 73 point 46 too; for 13 point 1 FIPS and NDcPP, it's 13 point 1 point 37 point 283. Secure Private Access Hybrid deployments using NetScaler need the upgrade as well.

And a trusted identity is doing the damage in GitHub, where hijacked maintainer accounts are committing a workflow called Security Audit under their owners' names. Socket counts more than five hundred accounts pushing it into tens of thousands of repositories since Wednesday. Any push can trigger it. It collects accessible CI secrets and searches the entire git history for credentials, including ones deleted from the current tree, then sends the haul over plain HTTP.

The name would almost be funny if it weren't running with your secrets. Check every repository, including forks, for security-audit dot yml or github_actions_security dot yml committed since the thirty-first of August. If found, treat it as compromise: revoke the hijacked GitHub credential and rotate every secret the workflow could reach. Remove the workflow from all branches, and hunt CI logs for HTTP traffic to 193 dot 32 dot 204 dot 199. No malicious package releases using the stolen publishing credentials have been identified so far.

From stolen credentials to access without any: AnyPwn is now a public working exploit giving pre-authentication root on AnyDesk Linux, before anyone approves the connection. Update to at least 8 point 0 point 3, or restrict TCP port seven thousand and seventy; June's fix was described merely as a crash bug, which rather undersold it. And there's a new chapter in the PaperCut patch saga: watchTowr details another authentication bypass in 26 point 0 point 4 dash PO build 76508, chained with a newly discovered code-execution flaw to restore unauthenticated access. Make sure NG or MF reaches 26 point 0 point 5, and keep it off the public internet while moving.

Away from servers, the P7 DarkSword iOS exploit-kit variant adds on-device keychain and crypto-wallet theft, with two-way command communication and a smaller footprint. Move managed iPhones out of its targeted iOS 18 point 4 to 18 point 7 band onto a current release. And back at the perimeter, Thursday's SonicWall position has changed: Previdian has detected SMA1000 exploitation attempts, though it hasn't established whether they'd succeed, and SonicWall's advisory still doesn't flag active exploitation. Install the hotfix today and hunt backwards for crafted OPTIONS requests to WorkPlace Extraweb that reach the appliance's loopback CouchDB service, invoking underscore rewrite with an admin colon admin Basic Authorization header.

I'd put an exposed Ahsay console ahead of the rest of the Saturday queue. And I'd check actual installed NetScaler builds, rather than trusting that this week's completed change means the job's finished. Hope the rest of your morning stays quiet.
