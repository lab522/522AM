[serious] The appliance checking your company's email can be rooted by sending it email. Cisco says attackers are already exploiting CVE-2026-76461 in Secure Email Gateway, its mail-filtering appliance. AsyncOS doesn't properly validate messages as it parses them, letting malicious S-Q-L statements become commands running as root. Nine point eight, and every physical or virtual gateway configuration is exposed. [short pause] No workaround. CISA's deadline for US agencies is Thursday, the seventeenth; I'd put it ahead of the ordinary patch queue.

[confident] Before upgrading, search mail_logs on every cluster member for the pattern COPY dot star TO PROGRAM. Cross-check off-appliance firewall logs for unexpected uploads: root access means attackers can hide the evidence on the box itself. [calm] AsyncOS 15 point 5 and earlier needs 15 point 5 point 5 dash 0141; 16 point 0 needs 16 point 0 point 4 dash 3021. Cisco recommends moving to 16 point 5 point 0 dash 780, which fixes that branch too. Compromised virtual appliances need rebuilding, with credentials and cryptographic material renewed; physical-box owners should contact Cisco T-A-C. The companion hardening release fixes five other issues and includes Secure Email and Web Manager: its fixed releases are 15 point 5 point 5 dash 006 or 16 point 5 point 0 dash 429. [serious] And a foothold doesn't stay on the first box. Acronis says Red Heron, a suspected China-linked actor, has compromised thirteen organisations across six countries through internet-facing Gitea, the self-hosted Git service. Within days of July's disclosure, public exploit code for CVE-2026-60004 became an automated framework that registers accounts before exploiting servers and stealing repositories. [curious] In one Taiwanese environment, that led to root on a three-node Proxmox cluster. That's the bit I'd investigate beyond the Git server. Patch exposed Gitea now, review new accounts and repository cloning, and replace secrets stored in repositories. Hunt Linux hosts for the JITTERLY implant and SIXZUT L-D underscore PRELOAD rootkit, which hides activity and relaunches if removed. A clean-looking process list isn't much reassurance there.

[curious] That same hop from developer tool to infrastructure took eight seconds in Sysdig's Marimo notebook investigation—but a human had spent four hours preparing the chain, not an A-I improvising at speed. Update Marimo to 0 point 23 point 0, authenticate or disable its terminal endpoint, and restrict Secrets Manager permissions so notebook credentials can't retrieve a bastion's S-S-H key. [serious] Meanwhile, exposed Vite development servers are being scanned for A-W-S and Azure secrets: affected versions are 7 point 1 point 0 through 7 point 3 point 2, and version eight before 8 point 0 point 5. Update, block external access to port five one seven three, and rotate reachable secrets. And public-facing WordPress sites have an older problem turning active: Wordfence says attackers are exploiting unauthenticated file uploads in WooCommerce Wholesale Lead Capture, disclosed in February. No fixed version is named; remove the plugin and inspect uploads and the web root for unexpected P-H-P files, then check for new admin accounts.

[long pause] [calm] A better development for the patch queue: those Remote Desktop Services failures we mentioned on Friday now have Microsoft's confirmation and September fourteenth out-of-band fixes for Server 2019, 2022 and 2025, plus affected Windows clients.
