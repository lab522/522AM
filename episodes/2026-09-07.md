# N-central’s fourth hotfix, and routers under attack

2026-09-07 · [listen](https://raw.githubusercontent.com/lab522/news/main/episodes/2026-09-07.mp3)

Four N-central hotfixes in five weeks, and even the previous day’s update isn’t enough. It’s Monday, the seventh of September, twenty twenty-six. I’m George, and this is The morning brief: public router exploits, database and Java traps, then active attacks on remote management platforms and online shops.

First, a limit on today’s numbers: the supplied material gives no EPSS probabilities, KEV status or due dates, and no confirmed ransomware links for these vulnerabilities. Public exploit code and confirmed exploitation aren’t interchangeable; I’ll keep those separate.

D-Link DIR-822A, build A_101, has a stack-based buffer overflow in udhcpcd’s serverpacket.c, involving strcpy. CVE-2026-86296 scores ten: low-complexity exploitation over the network, no credentials, no user interaction, with effects crossing a security boundary. Exploit code is public, but neither a fixed version nor a mitigation is supplied. If you run that build, establish its exposure and look for vendor guidance; there’s no patch number here to hand you.

Advantech has two command-injection flaws affecting WISE-6610 NB, EB, TB, JB and CB models, their EL variants, and WISE-6610P DEA, DNA and DTA models, on 1 point 2 point 1, build 20251110. The first, CVE-2026-79697, abuses the act argument in basicstation_apply, the Basic Station certificate-deletion handler. It scores nine point nine: low-complexity exploitation over the network, low privileges, no user interaction, crossing a security boundary. Its exploit is public; this entry supplies no fix.

The second Advantech flaw, CVE-2026-79698, puts the same dangerous act argument in nodered_lib_apply, in the Node-RED library handler. Again, nine point nine: over the network, low complexity, low privileges, no user interaction, crossing a security boundary. Public exploit code is available, and this one explicitly has a fix: 1 point 2 point 4, build 20260821. That fix is stated for the Node-RED issue; don’t silently count it as confirmation that the certificate handler is repaired too.

Linksys RE7000 firmware 2 point 0 point 15 has OS command injection in its PingTest handler, through the IP address, packet size or repetition-count arguments. CVE-2026-86299 scores nine point nine: low-complexity exploitation over the network, low privileges, no user interaction, with cross-boundary impact. The exploit is public, and no fix is supplied. A ping diagnostic becoming a command launcher is rather more functionality than anyone ordered.

For Java teams, Jetty has an unauthenticated heap-exhaustion route when WebSocket auto-fragmentation is enabled. An unknown opcode slips past normal maximum-frame-size handling, and a huge declared payload triggers allocation before opcode validation. CVE-2026-19204 scores eight point seven: over the network, low complexity, no additional attack conditions, credentials or user interaction, with availability impact.

Affected Jetty ranges are 12 point 1 point 0 through 12 point 1 point 11; 12 point 0 point 0 through 12 point 0 point 37; 11 point 0 point 0 through 11 point 0 point 31; and 10 point 0 point 0 through 10 point 0 point 31, inclusive. If you run those branches, check WebSocket auto-fragmentation settings. The material supplies no fixed release.

PostgreSQL Anonymizer has a masking problem with teeth: unprivileged masked users can plant untrusted expressions in operators, domain casts or view subqueries, then have masking machinery evaluate them with elevated privileges. Classified as SQL injection, CVE-2026-19633 allows arbitrary code execution and scores eight point eight: low-complexity exploitation over the network, low privileges, no user interaction, with scope unchanged. Versions from 1 up to, but excluding, 3 point 1 point 4 are affected. Upgrade to 3 point 1 point 4 or later.

Red Hat JBoss EAP 7 and 8 get an unsafe-deserialisation warning, although precise affected builds aren’t given. In Artemis, ObjectMessage.getObject() reaches a class loader whose default empty allow-list and block-list effectively trust every class. CVE-2026-86404 scores eight point eight: over the network, low complexity, low privileges, no user interaction, with scope unchanged. Check the Artemis deserialisation configuration if you use it; neither a fixed build nor a specific remediation is supplied.

For embedded teams, Nordic’s nRF Connect SDK from 2 point 2 point 0 through 3 point 3 point 0 has an out-of-bounds write in the Bluetooth Continuous Glucose Monitoring Service’s record-access write handler. CVE-2026-14297 scores eight point seven: its vector says adjacent-network access, low complexity, no additional attack conditions, no privileges and no user interaction, with high impact confined to the vulnerable system. But the description explicitly requires an authenticated BLE peer, so that access requirement needs clarification. The twenty-byte buffer overflows into neighbouring BSS memory; actual impact depends on the firmware’s linker layout, and no fix is supplied.

Now the operational news, starting with that N-central update treadmill. Every on-premises build below 2026 point 3 point 1 point 14 needs Hotfix Four for an unauthenticated remote-code-execution flaw described as maximum severity, including installations updated to Hotfix Three a day earlier. N-able’s incident notice says it has been exploited; its release notes say that’s unconfirmed, while BleepingComputer reports ongoing attacks. The reporting conflicts, but the upgrade threshold doesn’t.

MikroTik routers with internet-exposed SSH are being taken over through a chain of two recently disclosed flaws, including an SSH authentication bypass. MikroTik released a patch late last week; exact affected and fixed RouterOS versions aren’t in this material. SANS advises assuming compromise. If you operate exposed RouterOS SSH services, identify the vendor’s applicable patched release and investigate for takeover rather than treating the update as the whole job.

Adobe Commerce and Magento stores are being backdoored through the StyleSmuggler zero-day, which allows attackers to execute code. The supplied report gives no affected version range, access prerequisites or fix. If you run either platform, check for the vendor’s advisory and investigate for backdoors; there isn’t enough detail here to name a safe release.

ScreenConnect has two separate stories, and they must stay separate. ConnectWise has announced an unpatched Remote Access vulnerability, with temporary mitigations available and a patch planned later this week; the supplied excerpt omits both the affected versions and the mitigation steps. If you run ScreenConnect Remote Access, get those instructions directly from ConnectWise rather than improvising from the headline.

Separately, researchers describe worm-like activity using backdoored ScreenConnect instances to transfer and execute payloads on newly connected clients, including a four-stage VBScript chain. If you investigate this campaign, check ScreenConnect-mediated transfers and execution around new client connections. Nothing supplied links it to the newly announced flaw. Your remote-support channel is the delivery route here, not proof of which door the attackers first opened.

There’s also a public TantoSec exploit chaining an AES-CBC padding oracle in Telerik UI for ASP.NET AJAX into unauthenticated remote code execution. The important brake on the headline: it only works against a specific non-default application configuration, and Progress patched the chain in July. If you use Telerik UI, check the July advisory against your configuration and installed build; neither the configuration details nor version thresholds are supplied here.

Two breaches underline how much exposure sits off to the side of the main product. Mathspace says attackers stole data on more than a million students, staff and parents through its internal Metabase reporting system; the entry mechanism and stolen fields aren’t specified. Trezor’s August breach at logistics provider ShipMonk now affects eighty-one thousand customers, after another sixty-seven thousand US customers were identified. That report is about logistics data exposure, not evidence of hardware-wallet compromise.

Finally, watch HAProxy integrity if you support automotive or media organisations in South Korea: a reported North Korean Linux espionage toolkit embeds its backdoor in HAProxy for long-term surveillance. The material supplies no initial-access route or indicators. A proxy can be a very comfortable listening post.

Priority order: patch on-premises N-central to Hotfix Four first, and address the actively exploited MikroTik flaws using the vendor’s version guidance. Next, check exposed management services, Commerce stores and ScreenConnect activity, then work through the affected Advantech and PostgreSQL Anonymizer upgrades and the remaining product advisories. Watch for the ScreenConnect patch and the missing version details on today’s active-exploitation reports. Thanks for listening — I’m George, and I’ll see you next time.
