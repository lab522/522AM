Dell Secure Connect Gateway leads today: a specially crafted request can turn a missing authorisation check into remote command execution, and the fixed versions are available.

CVE-2026-61410 scores nine point four: over the network, low complexity, no credentials and no user interaction. It affects Secure Connect Gateway 5 point 0 Application before 5 point 36 point 00 point 00, and Appliance before 5 point 36 point 00 point 16. Upgrade to those respective releases or later; Dell recommends doing it at the earliest opportunity.

Those same releases also fix CVE-2026-80238, scored nine point three, involving unnecessary privileges and an exposed Docker socket. The vector says local access, low complexity, no privileges and no user interaction, but the description says a low-privileged operator with SSH access can obtain root without a password. That's a discrepancy worth retaining, not smoothing away: the described route starts on the host, not out on the internet.

A boundary on today's vulnerability figures: the supplied material gives no EPSS probabilities, KEV status or due dates, and no ransomware associations. That means unknown here, not absent. Public exploit code and reported exploitation will get their own explicit mentions.

D-Link DIR-822A firmware A_101 has a maximum-score stack buffer overflow in udhcpcd, inside strcpy in serverpacket.c. CVE-2026-86296 scores ten: reachable over the network, low complexity, no login and no user interaction. Exploit code is public, but the supplied record names no fixed release or mitigation and doesn't establish which deployments expose the vulnerable path. A ten deserves attention; it doesn't, by itself, tell you that every device is internet-reachable.

FreeIPA has a more alarming destination: an attacker-controlled Kerberos principal in the administrators group. CVE-2026-76578 scores nine point eight, over the network with low complexity, no credentials and no user interaction. Its self-managed OTP token access rule permits unauthenticated additions without restricting accompanying attributes; combined with a separately tracked directory-server access-control evaluation flaw, an LDAP client can create that privileged principal. The affected-product entries name Red Hat Enterprise Linux 7 and 10, but provide neither a precise package range nor a fix, so those details remain unresolved in this briefing.

Advantech has two public command-injection exploits against WISE-6610 gateways running 1 point 2 point 1 underscore 20251110. The named models are the NB, EB, TB, JB and CB variants of both WISE-6610 and WISE-6610-EL, plus WISE-6610P-DEA, WISE-6610P-DNA and WISE-6610P-DTA. CVE-2026-79697 targets the act argument in basicstation_apply, the Basic Station certificate-deletion handler: nine point nine, over the network, low complexity, requiring low privileges but no user interaction. No fix is stated for that flaw.

CVE-2026-79698 reaches command injection through the act argument in nodered_lib_apply, in the Node-RED Library component. It's also nine point nine: network access, low complexity, low privileges required and no user interaction. For this second flaw, upgrading to 1 point 2 point 4 underscore 20260821 is explicitly identified as the fix. Don't assume that statement also covers the certificate-deletion bug.

Linksys RE7000 firmware 2 point 0 point 15 has an OS command-injection flaw in its PingTest handler, through the target address, packet-size or repetition arguments. CVE-2026-86299 scores nine point nine: over the network, low complexity, low privileges required and no user interaction. The exploit is public, and no fixed firmware is named in the supplied material. A diagnostic ping shouldn't come with a command interpreter attached.

Bahçelievler Municipality's BiHayat app has an authentication-bypass disclosure caused by insufficient restriction of repeated authentication attempts. CVE-2026-6223 scores nine point four: over the network, low complexity, no credentials and no user interaction. The range starts at 2 point 1 point 7 and ends at the supplied label 07092026; no fix is stated, and the disclosure says the vendor didn't respond.

Now to reported attacks, starting with N-able N-central, where yesterday's hotfix may already be yesterday's news. Every on-premises build below 2026 point 3 point 1 point 14 needs Hotfix four, including servers updated to Hotfix three a day earlier, for an unauthenticated remote-code-execution flaw reported as maximum severity. The exploitation reporting conflicts: N-able's incident notice says it's been exploited, while its release notes call that unconfirmed. If you run an affected on-premises build, the concrete action is still Hotfix four; don't let the wording dispute obscure the version check.

MikroTik routers with internet-exposed SSH are also under attack through a chain of two recently disclosed RouterOS vulnerabilities. SANS describes an already-exploited SSH authentication bypass and says a patch arrived late last week; its advice is to assume compromise. The supplied reports don't name the affected or fixed versions. If your RouterOS SSH service is internet-exposed, establish the applicable release and investigate possible compromise rather than treating the update as proof that nothing happened.

ScreenConnect has two separate reasons to occupy your attention. ConnectWise has disclosed a new Remote Access vulnerability with temporary mitigations and a patch planned later this week, but neither the affected versions nor the mitigation steps are included here. Separately, researchers report worm-like activity using backdoored ScreenConnect instances and rogue clients to transfer and execute a four-stage VBScript chain on newly connected hosts. Check newly connected systems for that payload activity and investigate the ScreenConnect instance involved; these excerpts do not establish that the campaign uses the newly disclosed flaw.

Adobe Commerce and Magento stores are being backdoored through an exploited zero-day called StyleSmuggler, which allows code execution. No affected range, entry conditions or fix is supplied, so this is an active-compromise watch item without enough detail here to prescribe a version change. Telerik UI for ASP.NET AJAX has a more bounded story: TantoSec has published a proof of concept chaining an AES-CBC padding oracle into unauthenticated remote code execution, but only in a specific non-default configuration. Progress patched that chain in July; check the applicable advisory and whether that July fix is deployed, because neither the configuration nor the release number is in this excerpt.

Mathspace says attackers stole data belonging to more than a million students, staff and parents after breaching its internal Metabase reporting system. The supplied report doesn't identify the stolen fields or explain the initial access. The reporting system, not just the learning platform's front door, is the important detail here: an internal view of the data became the way out.

Trezor's August breach at shipping and logistics provider ShipMonk now affects another sixty-seven thousand US customers, taking the reported total to eighty-one thousand. This is a supplier breach; the material doesn't say hardware wallets were compromised. If you're following the incident, the revised customer scope is the update, while the data fields remain unspecified here.

Finally, researchers report a North Korean Linux espionage toolkit that embeds a backdoor in HAProxy, targeting automotive and media organisations in South Korea for long-term surveillance. If you investigate Linux infrastructure in those sectors, HAProxy itself belongs in the review, not just the traffic passing through it. No indicators, affected versions or initial-access route are supplied.

Patch first: the affected Dell gateways, on-premises N-central below Hotfix four, the applicable MikroTik release, and Advantech's explicitly fixed Node-RED flaw. Check next: possible RouterOS compromise, ScreenConnect payload activity, and whether the Telerik July fix is present where relevant.
