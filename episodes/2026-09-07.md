Email hello at lab522 dot co dot uk if you think we can help your business. If you run Dell Secure Connect Gateway, today's first job has a clear destination: fixed releases for two critical flaws.

For Secure Connect Gateway 5 point 0, upgrade the Application to 5 point 36 point 00 point 00 or later, and the Appliance to 5 point 36 point 00 point 16 or later. CVE-2026-61410 is missing authorisation, scoring nine point four: reachable over the network, with low complexity, no credentials and no user interaction. A crafted request can bypass execution restrictions and run commands remotely. That's a support gateway doing rather more supporting than you intended.

The same updates fix CVE-2026-80238, execution with unnecessary privileges, scoring nine point three. Its vector says local access, low complexity, no prior privileges and no user interaction, crossing a security boundary; the description specifically discusses a low-privileged operator with SSH access. That operator can use an exposed Docker socket to gain root without a password. Keep that distinction in your assessment: the described route starts on the host, not with an anonymous internet request.

D-Link DIR-822A firmware A_101 has a publicly disclosed stack-based buffer overflow in the udhcpcd component, in a strcpy call in serverpacket dot c. CVE-2026-86296 scores ten: over the network, low complexity, no login, no click, with impact crossing a security boundary. The supplied record gives neither a fixed release nor a mitigation, so there's no honest patch destination to read out here.

FreeIPA has a particularly ugly identity problem in CVE-2026-76578, scoring nine point eight. It's reachable over the network with low complexity, no credentials and no user interaction. The self-managed OTP token access rule permits unauthenticated creation and fails to restrict accompanying attributes; chained with a separately tracked directory-server access-control flaw, that lets an attacker create a Kerberos principal and put it in the administrators group. A token-enrolment door becomes an administrator entrance.

The affected-product entries name Red Hat Enterprise Linux seven and ten, but give no package ranges or fixed versions. Don't read that as proof that every installation is vulnerable. If you operate FreeIPA, the package-level applicability and the related directory-server flaw are the details you need next.

Two public command-injection exploits affect Advantech WISE-6610 firmware 1 point 2 point 1, build 20251110. The listed models are NB, EB, TB, JB and CB, their EL-prefixed counterparts, and WISE-6610P variants DEA, DNA and DTA. CVE-2026-79697 targets the Basic Station certificate-deletion handler through its act argument: nine point nine, over the network, low complexity, low-privileged credentials, no user interaction, crossing a security boundary. No fix is stated for that flaw.

CVE-2026-79698 targets the act argument in the Node-RED library handler on those same models and firmware. It also scores nine point nine, with a low-complexity network path, low-privileged credentials, no user interaction and impact crossing a security boundary. This one has a stated fix: 1 point 2 point 4, build 20260821. Don't assume that update also closes the certificate-deletion issue; the supplied material only confirms the Node-RED fix.

Linksys RE7000 firmware 2 point 0 point 15 has OS command injection in its PingTest handler, through the IP address, packet-size or repetition arguments. CVE-2026-86299 scores nine point nine: over the network, low complexity, low-privileged credentials, no user interaction, crossing a security boundary. The exploit is public, but no fixed firmware or mitigation is supplied. A diagnostic feature that accepts commands rather than just destinations is a fairly expensive ping.

Bahçelievler Municipality's BiHayat app has an authentication bypass caused by insufficient restriction of repeated authentication attempts. CVE-2026-6223 scores nine point four: over the network, low complexity, no credentials and no user interaction. The affected range starts at 2 point 1 point 7 and ends at the release identifier 07092026. No fix is supplied, and the disclosure says the vendor did not respond.

For these new CVEs, the material supplies no EPSS probabilities, KEV status or due dates, and no ransomware attribution. Those are unknowns, not reassuring zeroes. Public exploit availability is also not the same thing as confirmed exploitation.

Now to reported attacks, where N-able's N-central needs immediate attention. Every on-premises build below 2026 point 3 point 1 point 14 needs Hotfix Four, including servers updated to Hotfix Three just a day earlier. The flaw permits unauthenticated remote code execution and is described as maximum severity. Four hotfixes in five weeks makes the exact build number considerably more useful than the words 'recently updated'.

There's a reporting wrinkle worth preserving: N-able's incident notice says exploitation has occurred, while its release notes call that unconfirmed; BleepingComputer also reports ongoing attacks. You don't need to settle that contradiction before applying the specified hotfix. You do need to verify the resulting build, rather than counting yesterday's change ticket as completion.

MikroTik routers with internet-exposed SSH are being taken over through a chain of two recently disclosed RouterOS vulnerabilities. SANS describes an already-exploited SSH authentication bypass and says MikroTik released a patch late last week. The supplied reports don't identify affected ranges or the fixed version. If you run RouterOS with exposed SSH, get the applicable vendor patch details and investigate possible compromise; SANS explicitly advises assuming compromise in this situation.

Adobe Commerce and Magento stores are also under attack through the StyleSmuggler zero-day, which allows code execution and deployment of a stealthy backdoor. The excerpt supplies no affected versions, entry conditions, indicators or fix. For those storefronts, this is an incident-assessment priority, not yet a version-specific patch instruction we can give you.

ScreenConnect has two separate stories, and joining them up would be premature. ConnectWise has warned of a new Remote Access vulnerability, with temporary mitigations and a patch planned later this week; the excerpt doesn't reproduce those measures or name affected versions. Separately, researchers describe backdoored ScreenConnect instances transferring and executing a four-stage VBScript payload on newly connected hosts. If you operate ScreenConnect, retrieve the vendor's mitigation notice and check the provenance of clients and instances: the supplied reporting does not establish that this campaign exploits the newly announced flaw.

Progress Telerik UI for ASP.NET AJAX has a public exploit chaining an AES-CBC padding oracle into unauthenticated remote code execution. The important brake on the headline is that it only works against applications in a specific non-default configuration. Progress patched the chain in July, but the excerpt gives neither that configuration nor the fixed release. If you use Telerik, check both against the advisory before treating every deployment as equally exposed.

Two breaches put supporting services in the spotlight. Mathspace says attackers stole data concerning more than one million students, staff and parents after breaching its internal Metabase reporting system. Trezor says the August breach at shipping provider ShipMonk affects another sixty-seven thousand US customers, bringing the reported total to eighty-one thousand. Neither excerpt specifies the stolen fields; the Trezor report does not establish that wallets or funds were compromised.

Finally, a reported North Korean Linux espionage toolkit embeds a backdoor inside HAProxy, targeting automotive and media organisations in South Korea for long-term surveillance. That's a trusted traffic-handling process being used as cover, rather than an obviously foreign process waving from the process list. For organisations investigating that targeting, HAProxy binary and deployment integrity deserve attention; the excerpt supplies no detection indicators.

Patch first: N-central Hotfix Four, the applicable MikroTik fix, Dell's two gateway releases, and the confirmed Advantech Node-RED update. Check next: exposed RouterOS devices for compromise, Commerce and Magento stores for backdoors, ScreenConnect's mitigation notice and client provenance, and Telerik's configuration-dependent exposure. Watch for missing fixes and affected-version details, especially for D-Link, FreeIPA and the unresolved Advantech issue. 522 AM, brought to you by Lab522. Find us at lab522 dot co dot uk.
